I contributed a new feature to EcoTrace, an open source Python tool that measures the carbon footprint of code. I built an example and documentation showing developers how to correctly measure energy and CPU usage for Polars, a popular and fast data processing library.

My pull request was reviewed and merged into the main project by the maintainer, who called it an excellent implementation with strong test coverage.

A few things I'm proud of from this contribution:

- I explained a tricky timing detail in Polars so developers measure the real computation, not an empty placeholder.
- I tested my own accuracy claims before writing the documentation, instead of just assuming they were correct.
- When an automated code quality check flagged a false alarm in my code, I researched the right way to resolve it professionally, rather than ignoring it.

It was a great experience collaborating with an open source maintainer and seeing a real contribution accepted into a public codebase that other developers will use. Grateful for the welcoming feedback along the way.
